## 🎯 Sobre o Projeto

O **Desejinhos** foi criado para centralizar ideias de presentes, compras planejadas e objetivos pessoais em um só lugar. Com uma interface leve, responsiva e focada na experiência do usuário, o aplicativo facilita a organização por categorias, prioridades e links diretos.

---

## 🔗 Acesse a Aplicação
* **Produção (Web):** [desejinhos.lovable.app](https://desejinhos.lovable.app/)

## 🛠️ Tecnologias & Arquitetura

Construído com um ecossistema frontend moderno e ágil:
* **Framework:** React
* **Linguagem:** TypeScript
* **Estilização:** Tailwind CSS
* **Plataforma de Desenvolvimento:** Lovable (Vibecoding)

---

## ✨ Principais Funcionalidades

* **Gestão de Listas:** Adição, edição e organização rápida de itens desejados.
* **Interface Responsiva:** Experiência fluida tanto no computador quanto no celular.
* **Design Limpo & Intuitivo:** Navegação direta ao ponto, sem poluição visual.
